# Журнал изменений Safe Notes

Все заметные изменения в этом проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [1.0.0] - 2025-12-16
### Добавлено
- 🎉 **Первый публичный релиз!**
- Основной функционал CRUD (Создание, Чтение, Редактирование, Удаление) для текстовых заметок.
- Система поиска по заголовку и содержимому заметок.
- Подтверждение удаления заметок во избежание случайной потери данных.
- Кастомный сплэш-экран (экран загрузки) и иконка приложения.
- Адаптивный пользовательский интерфейс, созданный с помощью Material Design 3.
- Локальное хранение данных (приложение работает полностью оффлайн).

### Изменено
- Оптимизирована производительность списка заметок.

### Исправлено
- Незначительные исправления в обработке ошибок.
