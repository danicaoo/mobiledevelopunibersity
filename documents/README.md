# Safe Notes - Приложение для заметок

## Описание
Безопасное локальное приложение для создания, редактирования и управления заметками. Разработано на Flutter. Все данные хранятся только на устройстве пользователя.

## 📱 Основные функции
- 📝 Создание, редактирование и удаление текстовых заметок
- 🔍 Быстрый поиск по заголовку и содержимому
- 🗑️ Удаление с подтверждением
- 📱 Адаптивный дизайн под разные размеры экранов
- ⚡ Локальное хранение (работает без интернета)

## 🛠 Технологии
- **Flutter 3.x** (Dart)
- **Material Design 3** для интерфейса
- Пакеты: `uuid`, `flutter_launcher_icons`, `flutter_native_splash`

## 🚀 Быстрый старт для разработчиков

### Предварительные требования
- Установленный Flutter SDK (версия 3.x или выше)
- Android Studio / VS Code
- Эмулятор или физическое устройство

### Шаги установки
1.  Клонируйте репозиторий:
    ```bash
    git clone <ссылка_на_ваш_репозиторий>
    cd safe_notes
    ```
2.  Установите зависимости:
    ```bash
    flutter pub get
    ```
3.  Запустите приложение:
    ```bash
    flutter run
    ```

### 📦 Сборка релизной версии
Для сборки подписанного релиза для Android:
```bash
# Генерация ключа (если нет)
keytool -genkeypair -v -keystore android/app/release-key.jks ...

# Сборка App Bundle (для Google Play)
flutter build appbundle --release

# Или сборка APK (для ручной установки)
flutter build apk --release
```

```bash
# Запуск всех unit-тестов
flutter test

# Запуск widget-тестов
flutter test test/widget_test.dart

# Запуск интеграционных тестов
flutter test integration_test/app_test.dart
```
