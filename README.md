Использованные виджеты


Основные виджеты:

MaterialApp - корневой виджет приложения
Scaffold - базовая структура экрана
AppBar - верхняя панель с заголовком
Column - вертикальное расположение элементов
Text - текстовые элементы
ElevatedButton - кнопка с эффектом поднятия
Container - контейнер с заданными размерами
Row - горизонтальное расположение элементов
Icon - иконки (круг и треугольник)
SizedBox - отступы между элементами
Настройки стилей и цветов

Цвета:

Colors.blue - фон AppBar
Colors.green - фон кнопки
Color(0xFF2E7D32) - кастомный зеленый для текста
Color(0xFFFF9800) - кастомный оранжевый для контейнера
Colors.red - цвет круга
Colors.purple - цвет треугольника
Стили текста:

fontSize: 24 - размер основного текста
fontWeight: FontWeight.bold - жирное начертание
Различные цветовые схемы для элементов
Компоновка элементов

Вертикальное расположение через Column
Горизонтальное расположение иконок через Row
Отступы с помощью SizedBox
Центрирование элементов через Center и mainAxisAlignment
